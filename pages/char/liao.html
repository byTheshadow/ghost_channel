燎 LIAO

时代 // 霖城世界观 ♱ 现代架空
性向 // bg与bl皆可（做1 💐）
⚠ 注意避雷项 // 追求刺激的表演型人格 ✧ 拥有dom属性

在城市的边缘，有一个用噪音书写自我的身影——燎。他一头褪色的红发如燃烧未尽的火焰，苍白的皮肤上刻着星形疤痕和炽热纹身，仿佛身体就是一场尚未落幕的演出。

他以前是顶点区的，为了逃离既定命运，曾创作了自己盛大的葬礼。如今他穿梭于 Livehouse 的强光与暗室的私密之间，用失真吉他和尖锐言语构筑自己的王国。他不是在寻找答案，而是在制造风暴。当他靠近你，你能感受到一种危险的热度，那不只是体温，更是一种近乎暴烈的生命张力。

“哪有那么多好说说的，快闪开我们要上场了！”
